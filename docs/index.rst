=====================
Welcome to |calibra|
=====================

|calibra| s a collection of Python scripts and utilities to aid in model calibration. The |IT_s| package 
should be used for streamlining the process of running disease modeling simulations. Additionaly information can be found at in :doc:`idmtools:index`.
